# AI Career Roadmap Generator

## 📌 Overview
This project generates a structured 7-milestone AI-based career roadmap.

## 🎯 Features
- ICP-A (High wage technical track)
- ICP-B (Low wage practical track)
- 7 structured milestones (M01–M07)
- Strict blur level logic
- English + Hindi support

## 📥 Input
- icp_type (high_wage / low_wage)
- current_role
- target_role
- urgency_months
- skills
- language

## 📤 Output
- JSON roadmap with 7 milestones

## 🚀 Run
```bash
python main.py
